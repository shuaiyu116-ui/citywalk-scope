# 先行 · Citywalk Scope

“立大功汪汪队”携程黑客松自由探索赛道 Web Demo。把旅行需求变成可以检查、修改、试走和带出门的行程：**AI 选点规划 → 真实地点与约束校验 → 地图辅助出行**。

2026-10-17 已修复用户试用中发现的重复追问、地点匹配和界面流程问题，见 [修复与真实接口验证](docs/试用问题修复-2026-10-17.md)。W00–W14 的历史交付范围见 [交付与验收](docs/W14交付与验收.md)，旧 ZIP 未包含本次修复。历史站点 <https://citywalk-scope.onrender.com> 本次没有更新；本地完成不等于已上线。

## 启动

建议 Node.js 22 LTS，最低 18；无前端构建。全新开发环境执行：

```bash
npm ci
npm start
```

打开 <http://localhost:3000>。Windows 解压交付包后可运行 `Start-Citywalk.cmd`；需事先安装 Node，包内不含 Node 安装器。服务端只依赖 Node 内置模块，前端库已存放于 `public/vendor/`，直接 `node server.js` 即可运行，无需在演示机下载前端库。`npm ci` 用于恢复锁定的开发依赖。

无 Key 时可点击北京、上海、南京示例。示例是本地数据，地图底图、图片补充、道路计算仍可能访问网络。定制生成缺 Key 或服务失败会明确提示；网页不会拿上海示例替代其他城市的请求。

真实规划需在网页“连接设置”填个人 DeepSeek Key，或配置服务端 `DEEPSEEK_API_KEY`，并在服务端配置携程 MCP Token。网页个人 Key 优先，仅存当前标签页 `sessionStorage`；不会向前端返回服务端 Key，密钥不进入路书、分享或收藏。本地可复制 `.env.example` 为 `.env` 私下填写，不要上传；已有进程环境变量优先。修改 `.env` 后需要重启服务。

## 当前工作流

1. 输入自然语言及日期、每日时段、天数、交通、同行和步行预算；明确设置优先于模型推断。
2. 网页请求 `POST /api/agent-route`：DeepSeek 先提出主选、备选、顺序与理由，再查询真实地点。名称不一致时，AI 根据城市、名称和地址对照真实候选判定别名，只能选择已返回候选；模型坐标、票价、营业时间不作为事实落图。
3. 携程 MCP `query_ticket` 提供地点与来源；重复、歧义、异城或未找到会明确标记。网页缺 Key、不足两点或生成失败返回可恢复错误；示例入口独立，不会伪装成定制结果。部分结果会提示缺失地点及尚未安排的日期。
4. 后端获取交通并计算时间冲突，新规划可有限调整。已有行程的对话修改只执行用户要求并重算。前端展示旅行进度与可操作的结果，不展示工具日志、Token 或内部预算。
5. 用户确认采用后，同一版本化行程驱动卡片、按日 2D/3D、时间轴、导航和路书。编辑进入草稿，重算成功后提交，可撤销；候选不自动替换当前版。

旧 `/api/generate-route`、`/api/ctrip/pois`、`/api/walking-route` 保留兼容。POI 按钮读取地点，不是写入携程行程。这里只调用携程 MCP，没有对外 MCP Server / MCP App。

## 功能入口

| 需求 | 已实现行为 | 边界 |
| --- | --- | --- |
| 调整行程 | 多轮输入、偏好管理、换点/增删/排序/锁定/停留与交通编辑 | 摘要和偏好仅页面内存；本机恢复须全部地点重核才能可信多轮 |
| 多日与跨城 | 分日、移日、每日条件、预订交通和接驳缓冲 | 1–14 天、编辑后 2–50 站；初始顺序均分，非最优；车次住宿为用户记录 |
| 实际出行 | 分段交通、时间轴、高德跳转、一次定位或手动起点、附近发现 | 道路非实时；公交/未知方式不伪造；不是网页实时转向导航 |
| 预览 | 2D、故事卡、3D 试走、键盘与触屏切换 | 3D 是程序化空间示意；图片非实时街景 |
| 带走行程 | HTML 路书、打印/另存 PDF、公开 JSON 只读导入 | 当前已提交版，不含草稿；天气/租赁未查询；只嵌入已加载可读取照片 |
| 分享 | 完整快照片段链接、只读查看、地点重核后复制 | 非短链/访问控制/永久链接；复制清作者个人记录 |
| 收藏与恢复 | 本机命名/检索/最近 20 次主动保存/历史/备份/完整恢复 | 同设备浏览器 origin（含端口）；无云同步；恢复为未核实 |

公开文件、分享和库不携带 Key、完整对话、保存偏好、GPS 或内部签名，但**本次同行、住宿、预订、已游览和自由文字可能被保存或分享**。发出前审阅。“脱敏”不代表自动识别任意隐私。

高德国内底图、百度图片搜索与同源缩略图代理保留；携程图片优先。上海示例可回退对应本地参考图，其他点无图则占位。图片搜索不自动获得授权，来源标注不可删除。内部 WGS84，绘图/导航转 GCJ-02；默认道路仍为海外 Valhalla，不能保证全链路国内可用。
