## 交付内容与复现

最终包：`output/w14-delivery/CitywalkScope-W14.zip`。同目录提供 `CitywalkScope-W14.zip.sha256`、`RELEASE-MANIFEST.json`、`package-check.json`；包内也有清单（清单不哈希自身）。ZIP 根内为 `CitywalkScope/`，可用于 Windows 本地和 Node/Render/Docker 部署。

保留 server.js、lib、public（含 vendor 许可证/参考照片归属）、test 源码与离线 fixtures、scripts、docs、AGENTS、README、DEPLOY、锁文件、部署配置、空凭据模板与 Windows 启动器。test 是可复现测试源码，不是测试日志。排除真实 .env、凭据、node_modules、Git、output 历史包/截图/日志、浏览器缓存与临时产物；Node 运行时不捆绑。

生成脚本只复制白名单目录/根文件，拒绝符号链接及未审阅扩展名；输出目录已存在则拒绝覆盖，可指定新的简单名称：

```powershell
node scripts/build-release.cjs w14-delivery
node scripts/accept-release.cjs output/w14-delivery/verified/CitywalkScope output/w14-acceptance.json
```

打包时只在内存读取本地 .env/进程中 Token、API Key、Secret、Password 类配置，用于检查候选文件不包含这些值（至少 8 字符），另查私钥/API Key 常见格式，绝不输出值。空模板另行验证。此检查不是任意秘密自动识别器；显式文件白名单是主要隔离。ZIP 解压后逐文件字节比对（含点文件），清单记录路径/大小/SHA256；ZIP 另有 SHA256。

`stage/` 与 `verified/` 是本机打包验证工作目录，不在 ZIP 中；对外交付只取 ZIP、SHA256 与清单。历史 output 内其他 ZIP 不代表本版。

## 本轮验收范围

从解压包运行、无 .env/无 node_modules，服务监听系统分配的空闲端口；只验证包内静态依赖和此前未连续贯通的链：本地示例交通/排程 → 编辑提交 → 新草稿隔离 → 同版 JSON/HTML/分享 → 收藏备份/未核实完整恢复 → HTTP 全地点重核候选 → 新签名多轮修改 → 采用/连续撤销 → 原分享仍固定旧快照。

验收结果：**通过**。本机 Node v24.14.1，解压候选包无 .env/无 node_modules，43 个静态资源 HTTP 返回与包内文件相同，以上连续链一次通过；临时服务自动停止。最终包仅更新本轮状态文档，运行代码、启动配置、测试与脚本的 SHA256 与验收候选包比较一致后沿用此结论，不重复业务检查。

所有模型、携程、道路、图片上游由已有 w11-offline fixture 及其父 fixture 模拟，真实的是本地 HTTP 与包内业务模块执行。没有调用真实 DeepSeek/携程/百度/Valhalla，不把底图可达或模拟测试当真实验收。浏览器交互复用 W13 记录，未新增 UI 变化，未做全设备或读屏认证。详细结果在 `output/w14-acceptance.json`，打包证据在 package-check.json。
