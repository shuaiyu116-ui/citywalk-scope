## 行程与信任路径

- 当前提交版是地图、时间轴、卡片与导出的共同来源。编辑草稿、Agent/重核候选不提前覆盖它；采用检查旧 base、草稿/繁忙与未知确认，之后可撤销。
- 公开 JSON 和分享快照白名单输出，无签名；导入仅验证结构。分享副本重新查询全部地点，生成新身份，清除作者同行、住宿、预订、已游览与自填规则。
- 本人收藏完整恢复保留个人记录与原计划，去签名且强制 `unverified-local`。可手动编辑，可信多轮须全部地点重核；重核保留本人记录，只签新查地点。
- 签名仅证明服务曾输出，12 小时或重启失效；不证明营业实时有效、预订真实、行走完成。保存/导出时间不是核实时间。

`source: deepseek` 只说明模型生成，需结合 poiSource、evidence 和 warnings。demo/demo-fallback 是示例；shared-copy 是重查副本；local-rechecked 是本人重核。失败提案记录随示例返回，不代表示例就是该提案。

内部 WGS84，路径 `[lat,lng]`，高德 GCJ-02。MCP 默认 GCJ-02 来自历史样本判断，供应方文档未明确，不应重复转换。

公开文件、分享与库不存 Key、完整对话、保存偏好、GPS 或 proof；本次同行/住宿/预订/已游览和自由文字仍可保存或发出，需用户审阅。库备份无加密，脱敏不识别任意隐私。只读分享不自动查询地图、定位或远程照片。

照片搜索不等于授权/实时街景，本地参考图保留 ASSETS.md。国内高德/百度不意味着海外道路和托管始终可达；真实服务与托管待验证见 DEPLOY.md。
