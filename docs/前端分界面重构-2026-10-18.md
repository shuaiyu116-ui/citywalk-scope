# 前端分界面重构

日期：2026-10-18。按用户要求，将原先集中在同一个页面的功能拆成不同界面，主界面保留 DS 对话和地图。本轮是现有 Web 项目的单次前端修改，不重开 W00–W14 串行队列。

## 界面与职责

| 界面 | 地址 | 主要功能 |
| --- | --- | --- |
| 探索城市 | `/#explore` | 与 DS 对话、生成与确认新方案、2D/3D 地图、按天查看地点 |
| 行程编辑 | `/#itinerary` | 查看当前条件、编辑地点与分日安排、交通及停留设置、计算提交与撤销 |
| 图文路书 | `/#roadbook` | 分日图文介绍、酒店选择、地点试走、收藏、分享、下载与打印 |
| 导航发现 | `/#discover` | 高德跳转、出发位置、已游览记录、附近发现、携程地点查询 |
| 行程收藏 | `/#library` | 本机收藏、搜索与版本历史、重新打开、备份和导入 |
| 偏好设置 | `/#settings` | DeepSeek Key、规划所用出行条件、个人偏好管理 |

桌面使用固定侧栏导航，手机使用六项底部导航。统一调整页面标题、卡片、表单、操作按钮、留白、焦点和响应式布局；独立分享页 `/share.html` 与离线收藏页 `/library.html` 使用配套样式。

设置中的出行条件用于后续规划；当前行程的具体调整仍在行程编辑完成。分享、导出和地点查询等有明确起止的操作继续使用对话框。

## 页面与交互契约

- 六个界面是同一文档内持续挂载的区域，由 `public/workspace-router.mjs` 切换 `hidden`、导航选中态和标题焦点。切页不重新创建业务控制器，不清空对话、当前行程、编辑草稿、候选方案或撤销历史。
- 支持直接进入上述 hash、浏览器前进/后退及各页滚动位置恢复。既有分享片段 `#cw...` 不作为界面地址覆盖。
- `public/index.html` 保留原业务 DOM ID。`settingsDialog` 与 `libraryDialog` 现在是常驻页面中的 section；`poiDialog`、`roadbookDialog`、`shareDialog` 仍为 dialog。
- 进入包含目标控件的页面后，再展开 details、滚动和聚焦。出行字段位于设置页，使用显式 `form="routeForm"` 继续关联规划表单；校验失败先切到字段所在页，再显示原生校验提示。
- 地图与路书分别提供按日选择，保持同一活动日期。重新进入地图后更新地图容器尺寸；离开探索页暂停 3D 渲染，切换页面停止自动试走。
- 异步返回的新方案不会把焦点移入隐藏页面；全局提示保留进行中的规划、草稿及待确认方案入口。附近地点加入后进入行程编辑。
- 个人偏好内容显示于设置页；业务仍沿用既有本页会话及本机收藏机制，切页不意味着新增云端存储。
- 隐藏的原故事卡容器继续挂载，以兼容既有照片与导出逻辑。

样式入口为 `public/workspace.css`；独立分享/收藏页使用 `public/standalone.css`。原基础样式和动态业务组件契约保留。离线 shell 缓存升级至 **v1.7**，加入新的独立页样式。

用户提及的精确名称 `doubao-design` 未在当前技能库找到；本轮参考现有 HTML 设计指南中的信息层级、响应式与可访问性原则完成界面组织。
